# DialogueFoundry support

The configured and verified repository is
[kifayathusain/speech-to-text-windows-app](https://github.com/kifayathusain/speech-to-text-windows-app).
Use [Issues](https://github.com/kifayathusain/speech-to-text-windows-app/issues)
for nonsensitive bugs, feature requests and usage questions. The repository API
confirmed Issues enabled and Discussions disabled on 2026-11-06. No separate
support forum, Discussion category, email address or response time is promised.
Consult [Troubleshooting](documentation/TROUBLESHOOTING.md) first.

For a bug, provide the app version (currently `1.0.0`), source revision or package
identity, Windows version/build, display scale for UI problems, Python and provider
versions, FFmpeg/FFprobe versions, reproduction steps and expected/actual results.
Say whether assets were installed and verified. Use a short fictional input.

Review diagnostics before sharing. Replace usernames, absolute paths, private
filenames, dialogue, audio, project content and personal speaker descriptions.
Remove API keys, authorization headers, tokens, credential-bearing endpoints and
environment dumps. Reports and Director plans can include paths even when dialogue
is omitted. Do not upload the entire model/output folder or a saved private project.

For features, describe the use case and desired behavior without attaching private
material. For usage questions, include the command and sanitized error plus what
you have already tried. See [Security](SECURITY.md) for vulnerabilities and the
[Code of Conduct](CODE_OF_CONDUCT.md) for community behavior. Private reporting
contacts remain a configuration prerequisite.
