# DialogueFoundry preview limitations

- Application version is `1.0.0`; stable release readiness is not established.
  No downloadable release is endorsed by this documentation.
- The application is licensed GPL-3.0-or-later. Model cards still include
  restrictive and incomplete terms, and third-party binary source/notice evidence
  is not complete. See [Licensing](LICENSING.md).
- The full packaged workflow has not passed acceptance on a separate clean
  Windows 11 machine/VM. A development-host package run cannot establish this.
- Actual Windows 150%/200% scaling, all-controls keyboard coverage and dependent
  structured desktop acceptance remain pending.
- Audio Director AI planning is experimental. Live endpoint acceptance, human
  listening review and scaling coverage remain incomplete. Review all proposals;
  unsupported expressive controls do not become capabilities through prose.
- Local catalog coverage is British/American English; it is not a guarantee of
  every upstream language or regional accent. Edge service availability changes.
- Mixed-provider casting is available through Director CLI. The desktop planner's
  version-one proposal uses a conversation-wide provider.
- Local synthesis requires runtime and model installation. Network is needed for
  downloads, Edge and cloud planning. CPU performance varies; no benchmark claim
  is made here.
- Requirement ranges and missing wheel/hash/toolchain locks prevent exact rebuilds
  from just the manifests. Native binary provenance needs further review.
- CI configuration, signed application packages, public screenshots/demos,
  verified release checksums, and clean-machine evidence remain follow-up work.
- The repository is already public and Issues are enabled. Private vulnerability
  reporting is disabled and a private conduct contact is missing, as checked on
  2026-11-06; the maintainer must establish those channels.
- A separate secrets and sensitive-history scan is required before publication.
  Documentation review does not establish a clean history. Review prior public
  exposure and repository settings separately.
